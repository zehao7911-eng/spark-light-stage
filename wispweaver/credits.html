Wispweaver

Nine original lantern gardens, three creatures, three botanical environments. Draw closed loops around glowing wisps. Avoid the spiky brambles; a loop containing a bramble releases all its wisps. Each garden grants a star for completion, a star for avoiding brambles, and a star for gathering a group of three or four in one loop. There is no failure timer. Stillness slows the garden for seven seconds, once per attempt.

Real open-source foundation

The actual trail self-intersection scanner, line intersection routine, Point and Region classes are adapted from Coil by Hakim El Hattab, Copyright 2011, MIT licensed. These run in coil-core.js for every loop. See the full original license. Inspected upstream commit: ea6fd3afae10a6d8a53b07e82be4211619206ede.

The original full-canvas pixel-readback capture check is replaced with geometric containment for mobile performance and deterministic rules tests. The old jQuery shell, external donation widget, background image and WebGL texture are not used. New level rules, artwork, UI, sound, progression and storage are independently authored. This is an adaptation of the source mechanic, not the complete original Coil game.

Controls

Draw mode: hold, trace a loop and release. Closing within a small distance of the start is accepted. Tap mode: tap the loop's corners, then tap the first point again. Both modes use the same capture rule. Long trails fade from the beginning. Space activates Stillness; Escape pauses. Progress is saved locally when browser storage is available. Sound is optional and starts with a user gesture.
