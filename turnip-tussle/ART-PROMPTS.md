# Built-in image generation / prompts

All four artwork assets were made with the built-in image_gen tool and copied into this project, not an API/CLI fallback. No reference-video or Steam assets were extracted. Technical processing only: WebP compression, transparent alpha preserved, atlas component bounds/foot anchors registered. No chroma-key removal, painting or generative edits through Python.

Runtime paths: assets/garden.webp, assets/orchard.webp, assets/glasshouse.webp, assets/sprites.webp, assets/frames.json. Raw workspace originals: ../turnip-art-sources/garden.png, orchard.png, glasshouse.png, sprites.png.
