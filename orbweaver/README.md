# ORBWEAVER
An original eight-chamber browser puzzle, inspired by COCOON's portable worlds and biomechanical ruins. Original models, environments, rules, levels and synthesized sounds. This is a smaller guided puzzle adaptation, without the commercial story, maps or guardian battles.

Tap circular platforms to walk through currently powered paths. Take or place an orb with the primary button. Enter an orb only while it rests on a socket. Wake its inner core. Amber light powers amber bridges; green light powers green passages. A sleeping source may sometimes be used before charging when a chapter's gate requires it. Carry an orb into another world and leave it there: the enclosing orb now carries its contained world's light too. Cyclic world nesting is prevented. Sockets can power mechanisms remotely within the same world; some bridges require a specified socket. Return button walks to the inner entry and leaves, respecting blocked paths. Undo, reset and a one-step worker hint are available.

Eight chapters teach waking cores, two sources, carrying light inward, nested transport and borrowing green power to wake amber. Two optional motes in the introductory chamber; three in each subsequent chamber. Best steps and mote collection records unlock a saved replay archive. Current world, object locations, nested return stack, core states, collected motes and sound save locally. Walking and undo history do not persist. Hidden tabs pause walking.

English UI, touch and keyboard (Space primary action, E enter/return, H hint, Z undo). Mobile portrait/landscape layouts, capped pixel ratio, one shadow map, instanced framing rocks. WebGL required, with explicit graphics failure message. No external fonts, images, models or CDNs. Three.js r147 MIT license included. ZIP index.html is self-contained and works offline; the hint worker is constructed from the inline pure model. Browser storage restrictions can prevent saving.
