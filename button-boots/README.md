# Button Boots

An original, gentle HTML5 walking toy inspired by the independent-foot controls of Biped. All artwork is drawn in code; this is not a port and contains no commercial game artwork, audio, or code.

Drag a coral or blue boot onto a nearby platform. The other boot stays planted. Alternate feet, collect three bells, and bring both boots to the little house. Moving platforms arrive in route four; colored steps from route five need the matching boot. A dotted arc shows the maximum reach. Missed drops return safely; there are no lives or timers. Z or the undo button reverses a successful step. Restart and pause are always available.

Eight authored routes, four scenic palettes, three stars per route, a persistent route journal and unlockable Sage (6 stars) and Berry (15 stars) hats. Stars reward completion, all three bells, and at most two missed landings. A completed walk can be exported as a PNG postcard. Best scores are capped at 24; replaying does not farm stars. Saved walks open paused; a held drag is never restored. Blocked browser storage falls back to an in-memory session.

Open index.html directly or serve this folder. No build, network request, WebGL, or account required. Touch and mouse share the same controls. Escape pauses and Z undoes. Synthetic footfalls and bell notes start only after interaction; sound can be muted. Canvas 2D via bundled p5.js 1.11.11 (LGPL-2.1, see P5-LICENSE.txt), 45 FPS target, capped pixel density and effects. Performance varies by device; mobile verification uses browser emulation, not a physical handset.

Validation: all eight routes have engine-verified three-star solutions. Browser-native touch walked all eight routes, including matching-foot pads, with zero misses; landscape touch covered two routes. Cold-file mouse completed route one, keyboard undo, exact paused reload, mute persistence, PNG postcard export and an explicitly engine-earned 24-star cosmetic fixture passed. Layout checked at 320×568, 390×844 and 844×390 with simulated safe areas. Zero script errors or HTTP requests in cold-file testing. No physical phone was available.
