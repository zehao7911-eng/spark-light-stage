# Clink & Tidy

A one-finger magnetic sorting toy. Drag anywhere on the board to move the magnet. Loose objects attach into a springy chain of up to eight pieces. Move over the matching coral, mint or lilac tray; matching objects are deposited and other colors remain attached. Drop releases the trail; Repel pushes clutter apart. No timers or losses.

Three room styles, nine illustrated keepsakes, gently increasing object counts from 18 to 30, two reach upgrades funded by earned coins, a collection shelf, local saves, synthesized sounds and small vibration feedback where supported. English interface. Original Canvas art and local code only, no network dependencies or image generation.

Open index.html directly or serve the folder on any static web host. Mobile portrait and landscape supported. Browser storage is optional.
