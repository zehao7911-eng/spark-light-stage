# Thimbleguard pixel art

Generation mode: built-in image generation, not CLI/API fallback. Final images are copied into this game as lossless WebP, preserving generated transparency. No Python drawing or retouching was used.

## Shared visual rules
Midnight blue/slate structures, moss vegetation, warm cream, brass highlights and restrained coral enemies. Shapes use readable silhouettes and grouped square pixels with controlled material ramps. Strongest highlights identify the knight, crystals and gate. The HTML pixel font, canvas arrows, floor cracks, square particles and sprite atlas share crisp nearest-neighbor rendering. All inventory/field-note icons reuse the same atlas as actors on the board. Background density is lower contrast; numeric and action information stays real HTML.
