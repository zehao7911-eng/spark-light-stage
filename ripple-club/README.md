# RIPPLE CLUB

A small original 3D stone-skipping game. Swipe upwards to throw; angle the swipe left or right to aim. Swipe length sets strength. The stone falls under gravity, rebounds from the water with decreasing speed, and rings each floating hoop it actually passes through. Collect all three rings to complete a shore. Collected rings stay collected between throws. There are no lives, countdowns, purchases or retry costs.

Six finite authored courses cover Pinewater Lake, Canyon Springs and Frostbell Cove. Separated targets, rocks and gentle lateral currents change the best line. The first course can be cleared with one straight swipe. Gold goals are visible; silver allows two extra throws. Best stars are retained across replays. Six stars unlock the Sea Glass stone/jacket kit; twelve unlock Horizon. Kits are cosmetic and do not change the hit radius or gravity. This is a short campaign, not an endless set of unique levels.

CLUB contains courses, kits, Light View and optional Tap Controls. Tap Controls provide angle/power sliders and a SKIP IT button. Keyboard: Left/Right changes aim, Space throws, Escape pauses. Short, downward and cancelled gestures do not charge a throw. Touch targets are 44 pixels or larger. Mobile portrait and landscape are supported.

Active stones (including windup), collected rings, results, stars and settings are saved locally. Reloading an active flight opens a pause screen before movement resumes. Refreshing a completed course restores its receipt. Private or restricted storage may prevent saving; the game remains playable. Sound starts with user input. Hidden/background pages pause, and a paused scene stops its animation and sound.

The original rounded human has connected two-link arms/legs, fixed-size eyes, cap, backpack, coat, shoes and thumb details. The hand meets the release point; the stone has a short windup and the player turns to celebrate. Three original environments include dock planks/nails/grain, shoreline stones, reeds, trees, canyon strata and ice slabs. Water is a stylized animated shader with visible expanding impact rings and bounded droplets, not a fluid simulator. Circle contacts approximate the listed rocks; this is not a general rigid-body engine or photorealistic rendering.

The reference is [Sidewards](https://store.steampowered.com/app/1899000/Sidewards/). Its official description and official screenshot `ss_a9ebba4988346640fdc94ab87584d3a6978b5dcc` were reviewed for the shoreline, third-person throw and stone-skipping premise. It was listed as coming soon during research; no popularity ranking, full-reference play or visual parity is claimed. This independent compact touch game includes no commercial reference code, models, textures, voices or music. No image generation was used. The cover is an actual runtime screenshot. The original model/shapes helpers are adapted from the user's earlier project code. Bundled Three.js r147 retains its MIT notice in vendor/THREE-LICENSE.txt.

GameWave support is optional. Genuine positive-like and successful direct-comment callbacks unlock the Sunset cap and Rose wristband once per local browser profile. Unsupported prompts are hidden, listener failures do not block play, and the game never fabricates social events. Real GameWave host events and actual handset FPS/heat have not been validated. See GAMEWAVE-IMPORT.md.

`index.html` and `standalone.html` are identical self-contained builds with no CDN dependency; editable sources are included. The original SVG icon is embedded in the builds and also included separately. `python build.py` rebuilds both HTML files. Serve this folder with any static HTTP server, or open index.html directly where the browser supports local WebGL pages. ZIP imports should keep index.html at the root.

Run `node tests.cjs`, `node rig-tests.cjs` and `node sdk-tests.cjs` for the controller, actual generated-mesh rig and optional SDK mock checks. Tests do not establish subjective fun or a platform quality grade.
