# SKYBLOOM

Hold anywhere to lift a firework. Slide left or right to steer it, then release near the drifting paper lanterns. A real expanding burst lights nearby lanterns, which emit delayed secondary bursts. Light every lantern to finish the night. Short ground-level bursts teach a longer hold; retries cost no lives or currency. There is no countdown.

Six authored nights feature a festival street, a mountain observatory and a fairground. Separated groups, constellation layouts and gentle drift change the best launch point. Earn up to 18 best stars by finishing within each visible rocket goal. Six stars unlock the five-petal Blossom shell and twelve unlock the Ribbon shell. Shell shapes change the particles, not the hit radius. Replay any unlocked night freely. This is a small finite campaign, not an endless set of unique levels.

Touch: hold the sky, drag horizontally, release. Keyboard: hold Space, use Left/Right to steer, release Space to bloom. Escape pauses. An overlong hold blooms automatically at the upper flight boundary. Pause, blur and backgrounding release continuous input. Partially lit lanterns, pending chain rings, parked rockets, best stars, shell choice, sound and Gentle settings are stored locally. A restored rocket waits for a new hold. Rendering particles are transient. Saves may be unavailable in private or restricted browsers; play still works.

The original 360×600 code-drawn pixel artwork includes architecture, lanterns, crowd reactions, moving clouds, telescope details and a rotating fairground wheel. Firework particles, ring checks and audio voices are bounded. Audio is synthesized after user interaction. There are no downloaded commercial assets, external fonts, runtime libraries or image generation. The icon is original SVG and the cover is an actual gameplay capture.

The loose spectacle reference is [Fireworks Mania](https://store.steampowered.com/app/1079260/): its official description and official screenshot `ss_889b1a05eb7c670a2f3f56e64fb627c4ffa4212e` were reviewed for warm fireworks against layered night architecture. This game is an independent 2D touch chain-lighting design, not a reproduction of that first-person sandbox. No reference source, artwork, characters, branding, music or recordings are included.

GameWave's optional injected `window.neonlib` is guarded. Genuine positive-like and successful direct-comment callbacks unlock Blue Hour and Rose glow palettes once per browser profile. Unsupported or failed listeners are hidden. Neither SDK presence nor social interaction is required to play. See GAMEWAVE-IMPORT.md. Real host events and physical-handset performance have not been tested.

Open index.html in a browser, or serve this directory with a static HTTP server. The ZIP contains this directory's files at its root. `node test.cjs` checks authored gold routes, real hits/misses, free retry, interrupted holds, deterministic chain restoration, corrupted saves, bounds and steering. `node test-sdk.cjs` checks the optional adapter with mocks. Native browser QA completed all six nights and reviewed 320×568, 390×844, 568×320 and 844×390 layouts. These checks do not establish subjective fun or a platform quality grade.
