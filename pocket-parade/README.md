# Katamari: Pocket Parade

A self-contained, mobile-friendly HTML5 fan game inspired by Katamari Damacy REROLL. Original procedural models and synthesized audio; no extracted commercial assets.

Roll through three size challenges, attach everyday objects to the rotating ball, outgrow larger obstacles, dash, collect 24 object families and turn each parade into a star. Time expiry switches to relaxed free play. Goals unlock the next parade; collection and best stars save locally.

Controls: drag the screen or lower-left joystick; hold DASH. Desktop WASD/arrows and Space. Collection opens the stage selector. Pause stops play.

Open index.html directly, or serve this folder. No CDN or external asset requests. Editable JavaScript and local Three.js MIT license included. Browser requires WebGL. Mobile layouts and touch controls verified in browser emulation; physical handset performance varies.
