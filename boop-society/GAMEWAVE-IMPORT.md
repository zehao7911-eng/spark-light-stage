# BOOP SOCIETY import contract

Import BOOP-SOCIETY.zip with index.html at the archive root. Do not import the whole shared repository or add an enclosing folder. index.html is self-contained; standalone.html is identical. No CDN, authentication, SDK or external media is needed for the nine core chapters. English interface, responsive portrait/landscape CSS and a capped WebGL framebuffer are included. Editable sources, actual screenshot cover, original SVG icon, licenses and tests are included.

Official GameWave SDK reference: https://rg975ojk5z.feishu.cn/wiki/MQg7wMknzieOkukxyWVc4UB0nDh . The injected neonlib is optional and never awaited for startup. Each method is capability-checked. Async registration is accepted only on code0; partial/failed/hanging methods do not gate play. onLike requires a genuine positive status and a string project_id; a real direct onComment event, including an empty image-only comment, can grant a cosmetic. Count snapshots, unlike, registration success and historical state do not generate fake rewards.

A genuine supported like changes the player's ring to gold. A supported direct comment enables a cycling confetti palette. Both are optional cosmetics with saved flags; every chapter and species remains available through ordinary play. Callback guards prevent local duplicate rewards. The adapter validates its boop-society/v1 cloud envelope and suppresses writes after unknown/failed/timed-out loads. Max/union progress merges preserve the local active shot; no server-level exactly-once guarantee is implied.

GameStart occurs on the first actual launch, GameOver on completion or abandoning a begun chapter. Pause, settings, undo and reload do not fabricate new completed rounds. The host viewport bridge capability is guarded, while this game lays out from real CSS dimensions; the host must provide a usable canvas viewport. Actual App import, social operations and cloud persistence require supported-host testing. SDK mocks only were run here.
