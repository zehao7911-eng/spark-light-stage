# Table for One — reference study

An independently implemented HTML5 study of Rezona's Table for One: https://rezona.ai/game/pgcserver/play/OjxHzhfU . This is not the Rezona original or a source-code export. The independent artwork was generated for this study. No original game code or game assets are included.

Observed in the reference: dark restaurant, round green table, warm lamp and bottle, roaches, a waiter turning to watch, a tap on the plate completing the first course, a cloche interaction, score feedback and an unfinished-course timeout. Full original progression, exact timing, complete scoring and audio were not verified. This study recreates the observed loop and atmosphere and supplies its own six course configurations, timings, scoring and sound; it is not a 1:1 reproduction.

Tap the plate to finish a course and tap roaches to catch them. Do not act while the waiter is watching. Three mistakes or time running out ends the course; retry is free. Progress and sound preference are saved locally. Pause and tap RESET PROGRESS twice to start over. The sequence repeats after six courses. Game files run from a static server with no network dependency.
