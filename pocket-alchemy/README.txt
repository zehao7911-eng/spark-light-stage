POCKET ALCHEMY
Original p5.js HTML5 falling-material sandbox inspired by The Powder Toy (Steam1148350). This is a smaller original browser experiment, with original code and art; it does not reproduce the commercial game, its electronics, air-pressure model, maps or assets.
Open index.html offline, or host this entire folder on GitHub Pages. No network resources or WebGL required. p5.js1.11.11 bundled with LGPL2.1 license.
Paint by dragging/holding. Four simultaneous touch points; mouse supported. Sand, Water, Seed, Flame, Stone, Erase in main tray. More drawer: Soil, Wood, Oil, Lava, Ice, Glass, Spark. Brush radius slider. Six worlds: Garden, Cascade, Foundry, Snowglobe, Dunes, Blank. Rain, Pause (can paint while paused), Undo stroke (restores previous world and pauses), Bookmark/Restore exact simulation, PNG export and optional synthesized sound. Up to ten undo states.
Seed near wet soil/water and on a supporting surface sprouts into a plant with flowers. Flame burns wood/plants; oil produces a local fictional fire burst. Flame/water produces steam, lava/water stone, lava/sand glass, heat/ice water, ice/water frost. Spark interacts with sand/water/oil. Eight persistent discovery stamps with short recipes in optional journal.
Fixed192x244 grid at60Hz, capped3 updates/render;40FPS2D canvas render, DPR1.5 maximum. Stable grid on rotation; exact cells/lifetimes/tick/RNG/rain/scene stored in bookmark. Discoveries are retained globally, even when undoing/restoring. Bookmark storage and downloads depend on browser capabilities. Hidden tabs pause; resume discards hidden elapsed time.
English minimal UI, 44px+ buttons, mobile portrait/landscape. Reaction physics intentionally stylized, not a scientific simulator or real-world procedure.
Reference: https://store.steampowered.com/app/1148350/The_Powder_Toy/
