# Art and reference

Visual direction: [Fracture Point on Rezona](https://rezona.ai/game/pgcserver/play/gabSFRUb). The actual title, introduction and first chamber were inspected for white technical panels, gunmetal framing, concrete, cyan / amber portal energy and precise laboratory lighting. No completed reference chamber is claimed. Paper Armada's title was also inspected, then rejected because that direction had already been used.

BREACH CIRCUIT is an independently authored side-view movable-exit glass-breaking game. The reference's first-person controls, chamber layouts, branding, original artwork, music and code are not bundled.

Seven original bitmap images / sheets were created with the built-in image_gen tool from one consistent material brief and the inspected style reference: three empty laboratory environments, eight intact/cracked capsule sprites, four core variants, a cover and an icon. Full prompts are in `ART-PROMPTS.json`. Unchanged full-resolution PNG originals are retained separately; runtime delivery uses smooth WebP encoding, preserved alpha and measured atlas rectangles. The external reference screenshot is not redistributed.

Portal rings, physical trajectories, trails, shatter fragments, metal deflectors, bumpers, launch cradle and platform are code-rendered. Capsule fracture feedback combines an illustrated cracked state with individually moving shards. This is not a claimed destructible real-time 3D mesh. All audio is generated with Web Audio oscillators and a short synthesized glass-noise burst; no recording is copied.
