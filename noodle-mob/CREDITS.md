# Credits

NOODLE MOB is an original HTML5 snack-train service game created for this project.

Visual direction reference: [Pot Luck Panic! on Rezona](https://rezona.ai/game/pgcserver/play/lxabyWlV). Its public cover and live kitchen presentation were inspected for rounded toy forms, soft clay materials, clear silhouettes and the grouped coral, mint and cream palette. The reference's kitchen-counter cooking rules, human chef, branding, maps, interface, audio and original asset files are not included.

Eight original raster sheets/images were created using the built-in image_gen tool: three playable backgrounds, a six-object food atlas, a bowl / three-pose dumpling-chef atlas, nine plated collection dishes, a cover and an icon. The same style reference and art brief were used across the set. Exact prompts are in `ART-PROMPTS.json`. Unchanged original PNGs were retained separately; delivery uses smooth WebP conversion and measured atlas rectangles with alpha preserved. No external reference screenshot is redistributed.

The chef has three illustrated expressions with procedural breathing, running bob and tilt. Snacks spring along the travelled route. These are rendered sprite animations, not a rigged 3D character or a claimed multi-frame walk cycle.

Movement, guided routing, snack-train service rules, campaign, interface and effects are project source. All audio is generated locally through Web Audio synthesis; no recording or music is copied from the reference. No third-party game engine or runtime package is required.

Code: MIT, see `LICENSE.txt`. Project-specific generated artwork is supplied for use with this game; no third-party game artwork is bundled.
