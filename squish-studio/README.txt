SQUISH STUDIO
An original tactile browser toy. English interface. No network dependencies.

Pull: drag a jelly. Use two fingers to stretch opposite sides.
Squish: hold a jelly, then release to let it regain its volume.
Split: swipe through a jelly to create two smaller friends (stylized split).
Drop: choose a color, tap an empty spot. Up to twelve toys.
Bounce: toss the whole tray. Trays: five starting arrangements.
Studio menu: gravity, softness, exact bookmark/restore, PNG postcard.
Undo restores the previous physical state, paused. Bookmarks also restore paused.
Keyboard: Space pause, B bounce, Z undo, Escape close.

Run index.html directly or host this entire folder on any static HTTP server.
Mobile touch and multitouch; portrait and landscape; Canvas 2D, capped pixel density.
Soft bodies use a constrained particle ring, area preservation and deformable
approximate collision response. This is a playful simulation, not scientific FEM.
Bookmarks use browser localStorage; private/blocked storage can disable saving.
Optional audio is synthesized after an interaction. No recorded music or assets.

Reference direction: Fractala Sandbox's soft-material playground (Steam 3289350,
announced/unreleased at time of research). Original art, code, toys and UI;
not affiliated and not a reproduction of that product's engine or full features.
