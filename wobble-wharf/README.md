# Wobble Wharf

Drag parcels from the bottom shelf onto a tiny boat. Released cargo falls, rests on the deck or other parcels, and slides as the boat tilts with the weight distribution. Keep all cargo stable for three seconds to depart. Splashed parcels return to the shelf; there is no life limit. Turn selected cargo before placing it. Star ratings depend on spills, and completed voyages unlock the next delivery.

Four to eight parcels, different sizes and weights, six color palettes, local progression saves, original Canvas art, synthesized audio and optional vibration. English interface; mobile portrait, landscape and desktop pointer controls. No external dependencies. Open index.html or serve with a static host.
