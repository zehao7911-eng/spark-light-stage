# Prismwake

An original browser incremental action game inspired by Nodebuster's resource-to-upgrade loop. Hold and drag to fire; break crystals, chain through clusters, charge Overload, buy permanent upgrades and explore three sectors. The Amber Vault has armored crystals that split into smaller ones; the Rose Rift has drifting crystals and more explosive clusters. A 45-second session returns to the upgrade workshop. Sentinels appear midway and award bonus shards. Play continues indefinitely.

Mouse/touch supported. Arrow keys move and fire; Space starts a run or activates Overload. Progress saves locally. No external assets, services or libraries. Art uses Canvas; optional sound uses Web Audio. Hidden tabs and open dialogs pause the simulation. No offline earnings. All resources are fictional.

The packaged index.html contains all code and styles. Original editable files are included. Recommended hosting: any static HTTPS host including GitHub Pages.
