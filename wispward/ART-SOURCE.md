# Art source and visual rules

The built-in image generation tool created the original scene and object atlas. The game uses the final workspace assets below; each is a lossless WebP conversion, with the atlas alpha preserved.

- [room.webp](room.webp): 1672 × 941, the conservatory setting, used in the banner and surrounding ambience.
- [objects.webp](objects.webp): 1024 × 1536 RGBA, exactly 4 columns × 6 rows. Includes 3 explorers, 18 relic icons, a wisp, a chest and a marker. An edit corrected the actual alpha channel; the final file has transparent gutters. The initial RGB-background variant is not used.
- Palette: midnight plum `#242331`, teal `#274f50`, sage `#83a58c`, brass `#d2a15b`, parchment `#f1ddb2`, periwinkle `#8c82c2`, coral `#d48676`.
- UI/grid: code-native rectangular pixel bevels, consistent 6-column spacing, clear stepped decoration and dot/pixel symbols. Covered jade stones and light parchment open stones use distinct values. Clues use both number glyphs and color; art does not replace the clue.
- Heroes, relics, wisp and chest all share the same atlas, palette and rendering scale. CSS `image-rendering: pixelated` is used for the atlas. VT323 is unmodified and licensed under the included OFL.
- Feedback uses a short staggered tile reveal, bounded square particles, treasure pop-ups and restrained hit/ward accents. Reduced motion is respected; art does not block startup.

Not photoreal, not 3D, not smooth vector. Landscape image.
