# Mossbell — The Sleeping Hollow
An original, small HTML5 exploration adventure inspired by ANIMAL WELL's atmospheric pixel caves, environmental tools, chimes, optional secrets and creature interactions. This is an eight-chamber standalone game, not the full commercial game. All art, puzzles, code and synthesized sound are original. No external images, game assets, CDN, fonts or runtime downloads.

## Play
Move with A/D or left/right. Jump with Space/Up. E makes a bubble beneath your feet; press again to pop it. On phones, use the four large controls. Jump off a bubble to reach a shelf or cast a fresh one. Bubbles can also ring hanging chimes and distract moths. Chimes open the next passage. Eight faint eggs reward close exploration, adding companion portraits; four and eight unlock seed colours. A lake creates a bridge when its chime is awakened. New bubbles have a short grace period; older ones attract moths. A snatched bubble gives a recovery hop, and moth contact nudges rather than removing discoveries. Mushrooms bounce, wind carries bubbles, water and thorns return you to a safe entrance without losing discoveries.

The journal offers fast travel to visited chambers. Discoveries save locally at key events; reload resumes from the saved chamber entrance, not the exact midair position. There are no lives, purchases or timers. Finish the eighth chamber to awaken the hollow, then revisit rooms for missed secrets.

## Run
Open index.html or serve this folder with any static HTTP server / GitHub Pages. No build required. Six files must stay together. Portrait uses a following camera, landscape shows the full room. Canvas pixel scenes are 320x224; output DPR is capped at 1.5, particles at 150, sound voices at 16, bubbles at three. Simulation uses 60Hz fixed steps and stops when paused or hidden. Audio unlocks after an interaction; mute and reduced motion are supported. Browser viewport checks do not substitute for physical device testing.

Reference: https://store.steampowered.com/app/813230/ANIMAL_WELL/

All eight eggs add a constellation to the caves and unlock eight individually illustrated companion portraits. The initial moth room has safe ground for learning; later regions combine the systems.
