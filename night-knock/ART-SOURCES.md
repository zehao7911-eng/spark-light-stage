# Artwork sources

Reference inspected: https://rezona.ai/game/pgcserver/pv/xXCcKjnP/v21/dist/index.html

The actual title screen and emergency-broadcast introduction were viewed. No completed reference playthrough is claimed. The mobile inspection mechanic is an independent adaptation; the reference also contains exploration and dialogue.

Sixteen publicly served images are reused: eight resident peephole portraits, four transformed portraits, title key art, city night, door and wallpaper. Each original URL, original SHA-256, dimensions and compressed-runtime SHA-256 is in assets/PROVENANCE.json. Unmodified JPEG masters are retained under assets/originals. Derivatives use WebP compression; bootstrap.mjs contains small embedded derivatives of the same artwork for immediate display and slow-network resilience. Cover and icon are crops/compositions of the credited images with new title lettering/border.

No image-generation service was used.
