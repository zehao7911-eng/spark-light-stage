# Clockwork Orchard

An original, mobile-first HTML5 tower-defense game. Open `index.html` in a modern browser or host the folder as static files.

Tap a stone ring to build a tower, then start a wave. Tap a tower to upgrade or sell it. Move the fox guardian with the Guard button, and tap the field after selecting Sunburst to cast it. Every third cleared wave offers a permanent relic for the current run. Waves continue indefinitely and the best wave is saved locally.

All monster, tower, guardian, and interface icon animations are individual transparent GIF files in `assets/`. The game map is a separate WebP image. No game engine or JavaScript package download is required.

Art assets and game code created for this project.
