# Skyway Dispatch

An original illustrated rooftop courier game, inspired by the moving-platform idea in Clustertruck. Eight handcrafted highways, three optional parcels per route, moving trucks, fragile roofs, long-jump pads, checkpoints, perfect-landing chains and three earnable courier outfits. No official artwork, code or branding from Clustertruck is included.

Tap another truck roof to jump. Hold and drag to preview your landing; the convoy pauses while you aim. Release to leap. Pale gold landing rings indicate a reachable roof; red means a fall. Pink pads extend your jump. Cardboard roofs collapse after 2.3 seconds aboard. Reach the POST bus to finish. The three stars reward finishing, collecting all three parcels, and finishing without falls. Checkpoints keep a fall from ending your trip. Space jumps to the next main truck on desktop; Escape pauses.

Open index.html directly, or upload the complete folder to a static host. All assets are bundled. No installation, account, CDN, network request, or paid service is needed. Use a current browser with Canvas 2D and Pointer Events. Audio begins after a gesture; sound is optional. Touch input uses the same pointer handlers as a mouse. Portrait and landscape layouts preserve large buttons and safe areas. No physical-phone testing is claimed.

Progress is stored locally when browser storage is available. Private browsing or file URL storage policies may prevent persistence; gameplay remains available. Backgrounding pauses the game. The route book unlocks Mint at six stars and Lilac at fifteen. Postcard saves the current scene as a PNG when the browser supports downloads.

Rendering: original procedural Canvas 2D art via locally bundled p5.js 1.11.11. No WebGL is required. DPR capped at 1.5; effects and audio voices are bounded. p5.js license is included in P5-LICENSE.txt. Game code and illustrations are original to this project.
