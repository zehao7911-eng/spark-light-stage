# Orebound

Original HTML5 mining and lighthouse-defense game inspired by Dome Keeper's dig–haul–upgrade–defend loop. All code, illustrations and synthesized audio are original. No dependencies or build step.

Hold direction buttons or WASD/arrows to move and drill. Carry crystals back to the central surface dock to deposit them. Open the workshop at the dock; upgrade the drill, cargo capacity, cannon, or repair. The emergency lift brings you home from underground. During attacks, return to the dock, aim by moving over the sky, and hold Fire/Space or the sky to shoot. Defeat all enemies to earn crystals and start a fresh mining interval. Enemy waves and cavern depth continue indefinitely. Local saves preserve the cavern, resources, upgrades and progress. An interrupted attack restores surviving enemies and wave progress. Every third wave includes an armored guardian. Hold Fire for automatic targeting, or touch the sky for manual aim.

Serve this directory with a static server or GitHub Pages. Touch controls are included; audio starts after interaction. The game pauses when hidden. There is no real currency.
