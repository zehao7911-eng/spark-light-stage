Bonbon Billiards

An original miniature pool challenge built on real open-source billiards physics.

Source roots

Classic 8-Ball Pool by Chen Shmilovich, copyright2019, MIT. Actual Vector2, Ball motion/shooting and GameWorld collision/cushion/pocket code are adapted, with fixed-step seconds, numerical guards and new game lifecycle. This is a challenge adaptation, not a wholesale8-ball AI port.

Complete MIT license · Commit and source hashes · Original GameWorld source

Original presentation

Walnut/brass/velvet table, woven cloth, resin cue, glazed bonbons, trails, sinking balls and particles are all original Canvas code. Sound is original synthesized Web Audio. No original game sprites, recordings, fonts, online runtime libraries or analytics included.
