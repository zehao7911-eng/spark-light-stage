# SQUEEZE PLEASE!

Drag to squish. Lift to send. A very elastic internet game show.

One finger changes the character's width while height changes inversely. Release to send the shape through an actual 3D cutout. The green indicator previews a legal fit. A bonk returns to the same door for free, keeping earlier doors. SEND is an alternative to releasing. The slider and left/right keys adjust shape; Enter/Space sends, P/Escape pauses. No lives, countdown or idle progression.

Six shows contain eighteen authored door challenges across three coordinated studio settings. Rectangle, ellipse and diamond openings test different proportions. Breathing openings freeze at launch, avoiding a moving target after release. Paired gates require one shape to satisfy both. The collision model checks a conservative sampled cross-section, not a general fluid/soft-body simulation. Rubber deformation is a real three-axis model transform that preserves volume; facial features, paws and props stretch with the model.

Completing shows collects six themed stickers and unlocks Doge, Nyan Cat and Keyboard Cat alongside the starting Longcat. These are four visual/celebration variants with equal collision rules, not paid or stat-enhanced classes. Nyan has a rainbow trail and Keyboard Cat has piano-flavoured synthesized chimes. Earn stars for completion, no bonks, and two perfect fits. The optional ? nudge suggests a current fitting shape and caps that show's third star; assisted clears still unlock everything. Best stars/scores, cast choice, stickers, settings and current aim or flight save locally. Result claims are idempotent. New seeded Encore auditions follow the campaign, with bounded shapes and a show-index cap; these are not unlimited handcrafted scenes.

Original code, rounded models, environment geometry, UI, SVG icon, textures and synthesized sound were made for this project. Three.js r147 is bundled under MIT. Character homages reference [Longcat](https://en.wikipedia.org/wiki/Longcat), [Doge](https://www.dictionary.com/culture/memes/doge), Nyan Cat and Keyboard Cat. No original meme photograph, drawing, recorded soundtrack or video is included, and no creator endorsement or rights to the underlying meme characters are asserted. No image-generation service was used. The user's eleven finished-product recordings informed coherent presentation, direct feedback, complete progression and character-specific humour; their game assets/code were not copied. The cover is an actual runtime capture.

Open index.html or standalone.html for the self-contained classic HTML build. All game scripts, CSS and Three.js are inline; no CDN, API, remote font or runtime image request is needed. Editable modular files and vendor license are included; serve index-source.html over HTTP to edit. Run `python build.py` to regenerate the HTML and reproducible SQUEEZE-PLEASE.zip in the parent directory. Run `node tests.mjs` for model scenarios covering six shows, three seeded encores, physical fits, paired flight, breathing-lock behaviour, bonk recovery, idempotent rewards and saved-state bounds. Model tests complement actual UI play and visual inspection; they do not certify subjective fun or a platform grade.

Portrait and landscape use real HTML controls at least 44px tall. Short landscape has a separate control/status column. Render target is 40 fps (30 in Light mode), pixel ratio capped at 1.5 (one in Light mode), and logic runs at 60 Hz. These are configured limits, not measured physical-phone performance. Gentle motion reduces cosmetic wobble and confetti while preserving the timing of gameplay openings. Hidden tabs and orientation changes pause; pointer cancellation never sends a shape. Context loss shows reload recovery, denied storage permits session play, and refresh restores a paused run. Browser viewport testing is reported separately from physical handset testing.


Quality update (2026-11-02): The slider now displays the exact legal shape interval and its golden perfect-fit centre. This interval is computed analytically from the same sampled body used by collision; paired gates intersect their intervals. Directional cues help players adjust immediately. Moving openings and the fit band both freeze for the committed flight. Three consecutive perfect clears add 0/50/100 bonus points (+150 total), with a persisted streak receipt; bonks reset the streak without removing earlier doors. Older v1 saves keep their collections and default the new counters safely.

Body deformation has a small cosmetic elastic overshoot, facial blinking and eyebrows, flight/bonk/celebration mouth poses, a physical return from the failed gate, passing shockwaves, contact particles, crowd hopping and changing scorecards. Synthesized shape ticks, ready chimes and escalating streak chords complement visual cues. Gentle motion reduces cosmetics. Full graphics adds one capped 1024px directional shadow map; Light disables it. Tiny facial parts do not cast distracting striped shadows. A repeated floor texture replaces the earlier individual checker meshes. No handset FPS increase is claimed without physical measurement. Additional tests cover fit-band/collision agreement, streak payment, recovery and legacy saves.
