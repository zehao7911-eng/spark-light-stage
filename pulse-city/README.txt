PULSE CITY · RESCUE RUN

Open index.html through a local web server, or use the GitHub Pages link.
The game uses the supplied Ambulance.fbx and Ambulance texture.png.

CONTROLS
Phone: drag the left joystick to drive; tap a call card to select a patient; tap SIREN WAVE to clear nearby traffic.
Desktop: WASD / arrow keys to drive; space to use the siren.

RULES
Pick up flashing patients and take them to the hospital. You can carry two at once. Critical patients have less time but award more stars. A timely siren wave clears nearby traffic and gives a speed burst. Pickups, deliveries and cleared cars build your score. Each shift reshuffles calls, traffic and district lighting. Use your stars for persistent upgrades and play the next shift.

OFFLINE PACKAGE
Serve this folder locally. For example, with Python: python -m http.server 8000
Then open http://localhost:8000/ in a browser. Browser security prevents module loading directly from file:// on many devices.

This game uses Three.js (MIT license; see vendor/THREE-LICENSE.txt). All in-game text is English. No external network requests or tracking are required for play.
