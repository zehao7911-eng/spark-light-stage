# Wandering Atlas

An original pocket map adventure inspired by Carto's world-rearranging idea. No commercial game assets or code are included. All illustrations and sound effects are created in code; no network dependencies, image generation, advertisements or purchases.

## Play

Open index.html directly, or serve this folder with any static web server. Drag an island onto another to swap them. Tap an island to rotate its paths clockwise. Green edge dots show the part connected to the boat. Connect the boat, all three souvenirs and the lighthouse, then choose Explore. The fox follows actual connected paths, with a stop at each souvenir. A disconnected expedition returns safely to editing. Edit map cancels exploration without altering your arrangement.

Eight journeys feature different layouts, landmarks and woodland palettes. Finishing earns a star; staying within the displayed gold move budget earns another; solving without hints earns the third. Undo refunds moves. Hints place or orient one island and only forfeit the unassisted star, never access to the next journey. Collect six stars for a Heather scarf and fifteen for a golden crown. Revisit journeys in the Travel book. After the eight journeys, Remix produces further solvable seeded arrangements using the eight existing landscapes, rather than claiming infinitely unique scenery.

Keyboard: arrows select island (announced in the toast); Space rotates; Shift+Space selects a tile, then Shift+Space on another swaps; Enter explores or edits; Backspace undoes; H gives a hint; Escape pauses. Standard tab navigation activates buttons.

Progress and active arrangements are saved locally when storage is available. If storage is denied, play continues in memory. Pause, hidden tabs and window blur stop simulation and suspend sound. Cancelled touch gestures do not alter the map. Portrait and landscape layouts respect safe areas. Canvas pixel density is capped at 1.5, with bounded effect and audio voices. Photo saves a PNG postcard.

Restart resets only the current journey. Travel book and cosmetics persist. There is no account, real-money system, server or installation step. Native touch browser simulation and desktop browser validation are used during development; physical phone performance is not guaranteed by emulation alone.
