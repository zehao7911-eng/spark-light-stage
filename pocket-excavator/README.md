# Pocket Excavator

A one-finger excavation toy. Hold and drag the hammer to crack the stone. Golden glints contain coins. Switch to the brush to sweep exposed dust off a treasure; clear all nine cells around it to collect it safely. Find all three treasures and move to the next excavation.

Twelve original illustrated curiosities, three quarry palettes, repeatable procedural stone boards, coin-funded hammer upgrades, a museum collection, synthesized audio, particles, combo feedback, vibration where supported, and automatic browser saves. Scanning is free. No lives, timers, external assets, libraries or payments.

English UI, mobile portrait/landscape and desktop pointer controls. Open index.html or publish the folder on any static host. Storage failure does not block play.
