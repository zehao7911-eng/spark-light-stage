# Tide & Tile

Original compact HTML5 seaside-building game inspired by Townscaper's colourful walls, clay roofs, stone foundations, neighbour-driven architecture and instantly responsive building. Procedural models, canvas-painted brick/roof textures, synthesized sounds and gameplay code are original. No commercial game assets or image generation are used. This is a bounded browser interpretation, not Townscaper's complete irregular-grid architecture system.

Tap a pale guide house or a water-grid dot to add one floor. Tap a roof to stack another (up to four). Pick a colour for new floors. Remove deletes the top floor; Undo and Redo preserve edits. Drag to orbit, use rotation buttons, pinch/wheel or the zoom button. Three adjacent two-storey houses form a genuinely hollow arcade when the opposite sides are open. An empty tile surrounded on four sides becomes a garden. Higher towers receive pointed roofs, balconies and finials. Eight small postcard projects teach the rules and unlock colours, flags, flowers, lamps, a sailboat, finials and festival bunting; then varied endless sea-mail projects continue. Free building has no required pattern. The album retains completed towns and their rewards. Day, sunset and moonlight recolour the sea and light. Save a PNG postcard from the album.

English UI, portrait and landscape touch controls; minimum 44px buttons. Local current town, undo/redo, camera, colours, lighting, completed projects and up to24 saved towns persist. New island requires two taps and retains rewards. Scenes pause while hidden or in the album/completion overlay. Bundled Three.js r147 under MIT. The packaged index.html is self-contained and works offline with WebGL. No fonts, CDN, account, ads or server API are required. Use any static host, including GitHub Pages.
