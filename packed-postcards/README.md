# Packed Postcards

Original self-contained HTML5 packing puzzles inspired by Pakinpaks on Steam: https://store.steampowered.com/app/2707950/Pakinpaks/

Drag travel objects into the suitcase. Select an item, then tap Rotate (or R) before dragging to turn it. Drop a packed object back into the tray to remove it. Undo or Z restores the previous placement. Every item must fit without overlap before ZIP & GO becomes available. There is no timer or move limit. Optional guide shows a complete valid layout for eight seconds; match item numbers.

Three stars: packed bag, no guide, and at most item count + 4 moves. Best stars and unlocked trips persist. Collect a new postcard at each departure. First 12 trips introduce four destinations, larger suitcases and tighter combinations; subsequent generated trips continue indefinitely. Guaranteed solvable seeded rectangle partitions; shapes are rectangular footprints, not physical irregular collision shapes. Passport shows first 12 and later unlocked trips up to 48; next adventure remains unlimited.

Mouse and touch drag, pointer capture, portrait/landscape layouts, capped DPR 1.5/30fps Canvas2D, procedural original object illustrations. All dependencies inline in index.html. No CDN, installation, external artwork or image generation. Save contains active puzzle, rotations of packed objects, undo history, profile and sound. Backgrounding pauses; storage failures degrade gracefully. Mobile tests are emulated, not physical device benchmarks.
