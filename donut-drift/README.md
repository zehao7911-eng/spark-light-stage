# Donut Drift

Touch-friendly conveyor puzzle. Drag from the oven or an existing belt tile, visit numbered topping machines in order, and finish at the heart tray. Bake delivers five animated donuts. Backtracking erases the route; Undo removes one tile. Recipes unlock sequentially and stars save locally. Three toppings, plant obstacles, twelve initial recipes and further generated variations. English UI, original Canvas artwork, local assets only. Open index.html or use any static host.
