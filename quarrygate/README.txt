Quarrygate adapts the board rules and worker-based Monte Carlo opponent of Quoridor AI by Kyutae Lee, https://github.com/gorisanson/quoridor-ai (MIT, see LICENSE). game.js, worker.js and ai.js are the upstream runtime. Board artwork, interface, sound and campaign integration are new. Run index.html through an HTTP static server to use the AI worker. Standalone file viewers may use the simpler fallback opponent.
