SUS SHAKE — Unofficial Among Us fan game
Drag anywhere to tilt the ship. Hit all three glowing power cells with the crewmates, then roll the crew into the open airlock. Release to let the ship settle. Arrows / WASD also work. Escape pauses.
Each ship changes the cell layout, later adding crewmates and a third bumper. Finish before the bottom timer runs out. Cleared ships, best chain and mute preference are saved. Reloading restarts the current ship. No lives or paid mechanics.
Short comic 3D physics toy: bouncy swarm collisions, spring bumpers, tumbling crewmates, hat variations, gate suction, ejection chains and a big-visored finale. Photo button downloads a local screenshot and never uploads it.
Self-contained index.html, no external assets or network requests. Open in a modern browser with WebGL enabled, or host with GitHub Pages. Touch portrait first, landscape and keyboard supported. Hidden/blurred pages pause and silence audio; resume explicitly. Optional short vibration on supported phones.
All meshes, game code, textures and synthesized sounds are original fan creations. Among Us characters belong to Innersloth LLC. Not official, affiliated or the original multiplayer game. No official meshes, music, recordings or game files included.
