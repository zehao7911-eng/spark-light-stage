# Jelly Span

An original HTML5 elastic bridge puzzle inspired by tactile construction games. All art is drawn locally with Canvas. No libraries, fonts, CDN or external images required.

Drag a pink jelly from its tray to join two nearby nodes. Golden balloon jellies can connect to a single node and float upward. Green dotted previews show valid connections. Pink nodes need two connections. Reach the flower house, then tap Rescue to send the little passengers along the bridge. Use Undo or Restart freely. Save unused jellies and collect floating stars for higher ratings.

Six authored levels introduce longer spans, extra anchors, balloons and thorn obstacles. Later levels remix these constraints deterministically. Progress, best level ratings, and saved bridge construction use localStorage. Fixed-step Verlet physics, constraint solving, touch-friendly drag targets, page-visibility suspension, pause and gesture-activated synth audio are included.

Mobile: drag from a tray button to the scene. Desktop: drag or select a jelly and click to place. Serve this folder over HTTP or upload to GitHub Pages. `index.html` is at the ZIP root.
