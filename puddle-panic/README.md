# Puddle Panic

A compact original 3D HTML5 growing-hole game inspired by Donut County. Original procedural models, environments and synthesized sound; no commercial assets, image generation, CDN or account.

Drag or tap the ground to steer. Start with pebbles and cups, then swallow planters, crates, trees, snack carts and houses. Every swallowed object grows the puddle. Three duck charms hide beneath large objects in each town. In towns two onward, swallow a stone and press SPIT to launch it into the bell and lower the fence. No timer, lives or losing progress. Keyboard arrows/WASD steer; Space spits; Escape pauses.

Six themed miniature towns use shuffled object positions and different palettes; subsequent towns remix these six themes, rather than offering unlimited authored maps. Stars record a clear, three charms, and at most one spit. Each clear earns 14 pebbles, used for three rim colours. Charm book replays unlocked towns with a confirmation. State, unlocks, coins and sound save locally. Pause and hidden tabs stop gameplay; restarting retains rewards.

Open index.html locally or host on any static server. Packaged index is self-contained. ZIP root has index.html. Three.js r147 MIT bundled; license included. WebGL is required. Pixel ratio capped at 1.5, drawing at 30 FPS, fixed 60 Hz gameplay and bounded particles. Phone viewport/touch simulation tested; physical phones not available for verification. English UI.
