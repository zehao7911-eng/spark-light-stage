# SEND IT PARK

Sculpt the rail. Send your friends. Brake before they lose it.

An independently implemented single-player 3D coaster workshop. The first rail is ready: tap Send It for an immediate downhill ride. Drag any gold height node up/down, or select points 1–5 and use the height slider. Three fixed gold stamp rings reward different rail shapes. Hold Brake before sharp dips to manage panic. Full panic or a raised rail through a low arch triggers a free parachute rescue; the rail is retained for editing or a braked retry. No lives, payment, countdown, account or remote runtime assets.

Eight authored rail layouts introduce multiple dips, low arches, a tailwind, visible booster bed, deep swoop, opposing wind/night venue and a combined finale. Three venues are a seaside boardwalk, sunset rock canyon and moonlit cloud fairground. Some elements are shared across venues; these are not eight separately painted worlds. There are 24 best stars, best hype, eight tickets, two additional train paint palettes unlocked after two/five cleared rides. Bounded Encore reuses the eight layouts; it is not infinite authored content. A clear is one star, all three stamps another, and peak panic below50% the third. Best records cannot inflate through repeated result claims.

The controller uses an arc-length sampled cubic Hermite rail with gravity/tangent acceleration, friction, braking, curve-derived stress, gates and boosts. Cars are constrained to the rail; this is not a fully free rigid-body roller coaster. Minimum assisted speed avoids a dead stalled carriage. Parachutes and arm acting are presentation animations; no realistic passenger injury simulation is intended. The body/seat detail, wheel meshes, changing rider mouths, blinking, raised arms, fixed rings, spark bursts, rail supports, lights, pennants, stalls, Ferris wheel, clouds, canyon rocks and night moon were created as procedural geometry. Static scenery is merged by material; sleepers are instanced. Rendering targets40Hz (30Hz in Light) with DPR capped1.5/1; these settings do not establish measured physical-phone performance.

Reference research: the public Rezona Roller Coaster gallery entry was opened at `https://rezona.ai/studio/game`. A native pointer line produced rails and a moving ride camera with Stop Ride and progress bar. No full reference finish, copied media, source code, reference licence, popularity or platform-grade claim. Earlier Crayon Courier drew physics bridges/weights for a ball, Tiny Railway routed trains and Cart Riot steered a hopping shopping cart; those related games were checked against this different geometry-and-braking loop. The user's eleven finished-game videos inform direct acting/contact feedback and visible progression; sampling those videos is not a claim of full continuous play.

All original game code/art/UI/icon and synthesized Web Audio belong to this project. Three.js r147 is locally bundled under its MIT notice. No image generation, copied reference assets, recorded music, remote font or runtime CDN is required. The cover is an actual runtime screenshot, not concept artwork.

Touch: drag one captured gold node, or select a point and use the height slider. Send It launches, Hold Brake brakes, Rebuild retains the rail. Space sends/brakes, 1–5 selects a point, arrows adjust height, U undoes, P/Escape pauses. Pointer interruption restores the unfinished rail edit. Hidden tabs pause. Audio only activates after user interaction. Sound/Gentle/Light persist. Active rail, current ride, terminal result, tickets and paint save locally; storage denial still permits session play. WebGL failure/context loss exposes reload. Portrait close view follows the selected node; the mini-map shows the entire rail. Ride view follows the train more closely. Landscape and desktop place controls alongside the scene.

Open index.html or standalone.html for the all-inline classic build. The ZIP has index.html at root and includes modular source, pinned library, licences, deterministic route examples and tests. Modular index-source.html needs HTTP serving. Run python build.py to rebuild, node tests.mjs for controller scenarios. Native browser testing, public download verification and physical-device limits are recorded separately in the delivery report. routes.json contains tested three-star example rails, not a universal solver for arbitrary player drawings.


## Boardwalk art and feel rebuild

The first release was rejected by the user as too rough. This revision keeps the eight routes and saved tickets, and replaces the assembled first-pass riders and car treatment with seated articulated figures, shaped heads, eyes/ears/nose/hair, clothing pockets, hands, shoes, upholstered seats, enamel coach sides, safety bars, couplers and rotating wheel groups. Track trestles, cross bracing, deck grain, station marquees, planting and benches give the rail a supported place in the park. An ink/brass interface replaces the earlier thick pastel cards. This remains original procedural artwork, not imported commercial character models.

The camera uses an oblique view, compensates the initial handle/finger offset and holds still during direct rail dragging. Acceleration drives damped body/head inertia; braking changes the grip and button state. Advance curve warnings and explicit low-arch warnings explain an actionable correction. Rolling and brake-friction synth layers track motion; no recorded speech or music was added. Gentle removes cosmetic camera/acting oscillation and Light disables real-time shadow reception while retaining contact blobs. Static sun shadows are cached and rebuilt with scene/track changes; moving carriage shadows are soft projected blobs, not continuously recalculated realistic shadows. This revision does not claim physical-handset performance or commercial-art parity.

The official [Parkitect presskit](https://www.texelraptor.com/games/parkitect/presskit), especially screenshot01, was inspected for coherent trestles, stations, planting beds, materials and depth. It was an art study, not a reference playthrough or asset/code source. Native first/second rides, warnings/rescue, rail touch/Undo, layouts and save verification are recorded separately in the refresh delivery report.
