# TRUST ME, BRO

Pull gold. Keep the boss upright.

An original single-player 3D block-extraction inspection game. Drag a gold brick toward the camera. The grip follows the brick's long axis so a diagonal phone view cannot accidentally turn a downward gesture into a sideways shove. Long swipes commit a finite extraction after release; short releases leave the block in place to settle. A held Steady Pull button and keyboard Space/down provide an alternative. The round-arrow button or left/right keys selects another gold brick. U undoes; P/Escape pauses. No lives or countdown.

Six inspections introduce a basic alternating tower, a removable supporting row, a spring-stabilised hinged bench, a two-pylon bridge, a fan-assisted test and a tall final structure. Gold collection is the common goal; choosing which support to remove matters in later structures. Removing the wrong support can topple the engineer. Free Undo restores the prior pull, including removed blocks and score. Stars reward completion, no undo, and low wobble. Six certificates and best scores persist locally; clearing two and four inspections unlocks cosmetic cobalt and gold helmet/vest finishes. Bounded Overtime repeats these structural templates after the campaign; it is not an unlimited set of hand-authored worlds.

Cannon.js runs actual 3D box contacts, gravity, friction and point-to-point pulling joints. The held brick's rotation is stabilised and friction is reduced to make a one-finger grip forgiving. At the marked collection threshold the brick leaves the physics world and its visual mesh flies into a tray; it does not retain full physical collision throughout that collection flight. Other blocks, the top plate and inspector remain dynamic. This is a casual extraction model, not a full commercial Jenga simulator. The visible rounded pieces match simple box colliders rather than bevel-perfect collision surfaces.

Original code, human inspector model, environment geometry, generated textures, interface, SVG icon and synthesized audio were made for this project. Three.js r147 and Cannon.js are bundled under their MIT notices. No image-generation service, remote font, reference artwork, recorded soundtrack or third-party game script is required. The cover is an actual runtime capture. The user's eleven finished-product videos informed contact feedback, coherent miniature presentation and progression that visibly changes the structure. Those videos were sampled visually, not continuously played or audio-auditioned.

Reference research: the official [Jenga Cat Steam page/trailer](https://store.steampowered.com/app/3044040/Jenga_Cat/) showed a green alternating tower, a yellow cat, a desert setting and a reduced tower with score220/target200. No native reference play or full completion is claimed. This game uses an original human inspector, goals, structures, environment and visual language; it is not an official adaptation. Rezona's Pigeon Panic opening was also inspected, then excluded because an earlier project already used that flight/drop reference. No reference game code or media was copied. Prior falling-block stacking and wrecking-ball demolition were checked as related physics games with different central actions; no claim is made that block extraction is a newly invented genre.

Open `index.html` or `standalone.html` for the all-inline classic build. The modular `index-source.html`, source modules, pinned vendor libraries and licenses are included. Serve modular files over HTTP for development. Run `python build.py` to regenerate the self-contained HTML and root-index TRUST-ME-BRO.zip. Run `node tests.mjs` for the physical-controller regression scenarios. Tests cover all six inspections plus two Overtime templates, stable idle/no automatic completion, real unsafe-order collapse, free recovery, partial-pose restoration, input cancellation, committed swipes, inventory conservation and idempotent rewards. Native UI and visual verification are recorded separately.

Touch uses one captured pointer. Cancellation and interruptions restore the current pre-grab checkpoint; partially settling poses and completed results save. Hidden tabs pause. Audio starts on interaction. Full/Light and Gentle motion settings persist. Rendering is capped at40Hz (30Hz in Light), device pixel ratio at1.5 (one in Light), and fixed logical updates step physics at120Hz. These are configured budgets, not measured physical-handset performance. Gentle changes cosmetic effects, not the rules. Local textures and bundled scripts avoid a runtime CDN loading gate. WebGL failure/context loss exposes a reload action; denied storage still permits session play.


The three venues are a wood-grained workshop, an open rooftop with a modelled skyline and rails, and a night lab with a star/moon porthole, equipment and the visible fan in its inspection. The bridge camera widens and tall towers reframe so the helmet and lowest targets remain visible. Phone labels avoid clipped world text; desktop controls sit beside the play area rather than over the tower. Fast clean pulls and slow creeping pulls can have different physical outcomes. Third-star late-stage routes were checked with clean fast input as well as the held-button route; a slow creep is not universally safer.
