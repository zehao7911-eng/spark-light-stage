# Sticker Sprout

A small, touch-friendly HTML5 sticker studio inspired by the create-and-pack loop of Sticky Business. All illustrations are original local SVGs; no external libraries, fonts or network assets are required.

Choose the customer’s illustrated animal, add the requested decoration, arrange up to five details, and change the colors. Print a sheet, pull each sticker diagonally toward the top left, drag it into the envelope, then swipe the sealing tape from left to right. Ship it to earn coins and build your collection.

Orders gradually grow from one to three stickers. A new animal unlocks every two completed deliveries, up to twelve; six decorations and six palettes allow custom combinations. Four deliveries complete a mail day. Orders continue without a timer. Progress and unfinished orders save in browser storage when available.

Open index.html directly, or serve the folder through any static host. English interface, pointer/touch controls, portrait and landscape layouts. Audio starts only after interaction and can be muted.
