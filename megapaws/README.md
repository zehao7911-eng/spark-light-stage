# MEGAPAWS

An original, playful 3D cat-and-city game inspired by the destruction premise of Pawperty Damage. Move with the joystick or arrow/WASD keys; bump into houses or use Pounce. Clear each target before time runs out to unlock the next of three districts. Space activates Pounce on a keyboard. Sound and pause are optional.

Run `index.html` through a static HTTP server. Works as a self-contained HTML5 build and does not require a CDN. A WebGL-capable browser is required. All game text is English.

Optional GameWave integration is guarded: the game works without the host. Successful like and comment events unlock cosmetic accessories and progress is stored locally; supported host cloud save is also attempted. Host integration must be tested inside the actual GameWave environment.

Rendering: Three.js (MIT); physics: cannon.js (MIT). See vendor license files.
