# HOLLOW GATE

An original compact 3D HTML5 action adventure inspired by Death's Door's isometric autumn estates, ivory stonework, crow silhouette, sword/roll/ember combat and quiet exploration. Original models, layouts and synthesized sound effects. No commercial assets or image generation are used. This is a six-area browser interpretation, not the full commercial game.

## Play

Move with WASD/arrows, the touch joystick, or tap the ground to take a safe path. Slash with J/Space or hold SLASH for a three-hit combo. Roll with K / ROLL: a short invulnerable dodge with a cooldown. Ember with L / EMBER: unlocked in area 2, costs one of three charges, replenished by sword hits and broken pots. Auto-aim points at a nearby enemy or unlit brazier; movement remains yours. E / the contextual button uses a shrine, bell or gate.

Six linked areas: autumn garden, urn court, flooded archive, village, three-wave orchard and the Last Gardener. Clear guardians to open gates; the archive also requires three lit braziers, the village requires ringing its bell. Three seals, six optional hidden relics, two two-tier upgrades, breakable pots and rest shrines. The boss alternates a radial slam with a charging attack and speeds up below half health. After victory, explore missed relics or replay a stronger boss rematch.

Health, ember, current position, defeated enemies, pots, seals, relics, upgrades and journey record save locally. Death retains earned rewards and defeated ordinary guardians; retry returns to the current shrine. The boss resets on death. Restart replaces the current journey and keeps completion records. Sound is opt-in. The hidden browser tab pauses. The trail ring and minimap show the next objective.

Open index.html directly or host the folder on a static server / GitHub Pages. Bundled Three.js r147 (MIT; see THREE-LICENSE.txt). No network dependencies. Native touch support, portrait/landscape responsive UI, targets at least 44 CSS pixels, cached/batched static scenery, 30 FPS art updates and pixel ratio capped at 1.5. Requires WebGL.
