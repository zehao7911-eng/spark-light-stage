NEON DRAGNET · NIGHT PURSUIT

Open index.html through a local web server, or use the GitHub Pages link.

CONTROLS
Phone: drag the left joystick to drive; tap SCAN to lock a target and reveal its future route.
Desktop: WASD / arrow keys to drive; space to scan.

HOW TO PLAY
Follow the radar, scan the target, then intercept its moving car before the case timer runs out. The scan reveals several future turns, and the camera briefly widens to show more of the city. Collect glowing intel along that route for extra stars and faster scan recharge. Arrests build a chain and add time; traffic collisions and escapes cost time. Each patrol changes targets, routes and district lighting. Stars buy permanent engine, scanner and patrol-time upgrades.

MODEL AND TECHNICAL NOTES
The patrol vehicle is a mobile-optimized GLB converted from the Car.pmx supplied by the user, with the supplied texture. The user confirmed authorization for use and public distribution. The original PMX and texture source files are omitted from this package; the playable GLB is included. This is an unofficial fan project and is not affiliated with the original game publisher.

This game uses Three.js (MIT license; see vendor/THREE-LICENSE.txt). All game UI is English. Play requires no external network requests or tracking. For local testing, serve this folder with a static web server (for example: python -m http.server 8000), then open http://localhost:8000/.
