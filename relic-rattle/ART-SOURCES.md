# Art sources

All sixteen source images are publicly served by the Rezona Shrinebreak reference at https://rezona.ai/game/pgcserver/pv/uyEbwmZc/v1/dist/index.html . See assets/PROVENANCE.json for one-to-one source URLs, original file names, SHA256 values and runtime processing. The original image files are bundled unchanged in assets/originals.

Runtime changes: three floors resized to800px and compressed as WebP; actor sheets' nine existing poses cropped with shared bounds and repacked to576×576; other transparent cutouts resized to256px. No new animation frames, model rig or media license was generated. Prepared media remain third-party derivatives excluded from the independent source-code MIT license. Marketing compositions retain the same exclusion when they contain those cutouts or backgrounds.

The flail's chain, motion trails, fragments, contact rings, projectiles and shockwave are original Canvas drawing. Recorded reference sound/music and fonts are not included; runtime audio is original synthesis.
