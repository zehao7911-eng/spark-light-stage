# Spoon Summit — Let Him Cook

One chef. One pot. A very long spoon. An original small 2.5D physics climber rendered in 3D. Climb to the dinner bell by planting your spoon against shelves, dragging to lever the pot upward, then releasing to fly with the resulting momentum. Touch and drag anywhere on the play view or the lower pad. Downward spoon movement pushes the chef up; sideways movements change the arc. Space grips; arrow keys move the spoon; Escape pauses.

## Three complete kitchens

Counter Culture has seven wooden ledges; Cold Feet, Hot Pot has eight slippery ice ledges; The Midnight Feast has nine gilded serving ledges, including moving trays. Each has three physically collectible golden bites, a real final bell, a receipt and repeatable best results. Finish / collect all three bites / use no rescue earns up to three independent stars, nine total. Three stars unlock a wider copper ladle and seafoam pot; six unlock a longer whisk and plum pot. Changes affect actual grip radius or maximum reach. All three courses unlock sequentially through completion. This is a finite compact three-course game, not an endless campaign.

Landing higher earns points once for the new highest ledge. Every two achieved ledges bank a safe flag, including a lower safe flag skipped by a larger jump. Falling below the safe height or pressing BACK TO FLAG returns to that flag, retaining collected food and score, counting a rescue. There are no lives, payments or permanent failure. Best-only records prevent replay farming. Replay is for cleaner climbs, missing food and earned tools, not a mandatory grind.

## The movement model

The chef moves in a vertical X/Y plane with velocity, gravity, air damping and one-way shelf contacts. The spoon plants against nearby top surfaces while held. A spring constraint applies forces opposite the requested tool offset; releasing a planted spoon releases bounded stored spring energy as well as current momentum. The quick-release impulse works even when no animation frame ran during a short gesture. Holding/releasing in free air cannot create that impulse. A grounded press automatically settles the tip onto the supporting shelf to make touch planting practical. Pot-rim contact is forgiving. Easy Climb defaults ON, reduces gravity, widens landing tolerance and steers gently toward a nearby ledge only while descending; it can be switched OFF without losing stars. This is an original arcade constraint model, not full rigid-body hammer/pot simulation, full ragdoll articulation, or the reference's exact controls. Platforms are one-way while rising. A free spoon relaxes back toward its resting pose.

Local saves include profile, exact active position/velocity, reached flags, score, collected bites and settings. Active reloads start paused and release stale pointer anchors without applying a launch impulse. Pausing, blur, cancellation, resizing and page exit cancel stored input force rather than launching the chef. Audio is silenced while paused/backgrounded. Storage errors leave an in-memory session playable.

## Run / edit

Serve this directory over HTTP (e.g. python -m http.server 8000) and open index.html. index.html and standalone.html are identical self-contained runtime pages. Editable modules, test controllers and local vendor source are included. Rebuild with python build.py; run node tests.mjs. Tests search valid physical input gestures and simulate them; no runtime debug win API is shipped. The root-index ZIP is suitable for importing the whole game.
