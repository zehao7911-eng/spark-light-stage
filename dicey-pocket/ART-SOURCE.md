# Art sources

Built-in image generation was used on 24 October 2026. The commercial screenshot was inspected as a style/composition reference only and is not shipped. No commercial image, sound or font was extracted into the game.

Selected runtime assets:

- `characters.webp`: 40 registered character portraits, encoded losslessly from `exec-dc62758b-b1a9-433e-9f05-ea4fcca47bce.png` in the task generated-images folder. 1586 by 992 RGBA, eight columns and five rows; CSS percentages select one cell.
- `stage.webp`: the painted dungeon stage, encoded losslessly from `exec-c3597b74-543e-4038-aa6c-934ac21c8fdd.png` in the same folder.
- `Kalam-Regular.ttf`: original font file from `google/fonts/ofl/kalam`, redistributed unmodified with `FONT-LICENSE.txt`. The CSS family alias is DiceyHand; the font data itself was not renamed or modified.
- Equipment/status glyphs, generated die textures, geometry, particle effects and synthesized audio are from the MIT source implementation.

The first character atlas (`exec-fc0f20e9-fa44-4740-a54e-2de3210a9d34.png`) was rejected for cell bleed. The final atlas was edited to separate the sprites; no Python painting, background removal or other creative raster edits were used. Python/Pillow performed only lossless format encoding for shipped illustrations.
