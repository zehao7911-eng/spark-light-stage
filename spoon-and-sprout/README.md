# Spoon & Sprout
Original incremental excavation game for mobile and desktop. English UI, procedural pixel artwork and synthesized audio. Inspired by the digging, upgrades and automation loop of Dirt Clicker, with no borrowed game assets.

Hold or drag on the soil to dig. Space also digs. Dirt and treasure automatically turn into coins. Upgrade your tool for more power, wider strikes and eventually a 3x3 area. Hire mushroom buddies, stone gardeners and root druids to automate digging. Lucky clovers seed more treasures. Breaking 20 tiles charges a root burst. Clear 65% to go deeper; 80% of a new region uncovers its giant relic; clearing every tile earns a bigger layer bonus. Six visual regions, eighteen treasures and increasingly valuable layers. Progress and current tile damage save locally. Helpers work while the page is visible; menus and hidden tabs pause.

No external dependencies or assets. Extract the ZIP and publish index.html on any static host. Packaged index.html is self-contained. Editable source files are included.
