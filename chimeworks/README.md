# Chimeworks

Original HTML5 incremental physics toy. Drop coins, earn brass from collisions, fit bells/springs/prisms, automate and rebuild for permanent multipliers.

Touch, mouse and Space supported. All art is drawn in Canvas; chimes use Web Audio after the sound button is enabled. No external requests or dependencies. Progress saves in localStorage. Simulation pauses when hidden or help is open. No offline earnings. The package index.html is self-contained.
