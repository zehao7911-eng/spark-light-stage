# Sugarline
An original HTML5 cloud bakery, inspired by the conveyor-and-topping satisfaction of Freshly Frosted. All illustrations, code, sound and puzzles here are original; no commercial assets or network libraries.

Connect the oven to the gift box through the displayed topping sequence. Drag or tap adjacent tiles. Retrace to shorten a route; undo and clear are free. BAKE sends three donuts through the actual route, transforming them at the machines. Invalid routes highlight the missing or out-of-order station. There is no timer and no lives.

12 recipes across berry garden, peach terrace and moon kitchen; stars reward finishing, a short route, and no hints. All recipes can be replayed from the collection. Progress and partially built routes save locally where storage is available. Sound starts after interaction and can be muted.

Serve with any static HTTP server or GitHub Pages. index.html is the entry point. No build step, CDN or runtime downloads. Canvas rendering is capped at 40fps and DPR 1.5, particles at 100, audio voices at 13; background tabs stop simulation and audio. Phone portrait and landscape layouts use the same game rules.
