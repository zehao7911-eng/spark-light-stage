WOBBLE WIZARDS — original physics tower trials

Drag the active brick sideways, release a drag to drop; a tap only positions it.
Buttons move one tile, rotate90 degrees and drop. The translucent landing ghost
is a vertical bounding-box estimate; sloped contacts can settle differently.
Drop moves the brick near its landing then releases it into real rigid-body
physics. Bricks can tilt, slide, push neighbours and fall off the foundation.
Build the target number of retained bricks. Lost bricks are replaced;3 losses
end the trial. A final brief settling period precedes the reward.
Fix anchors the latest settled brick; charges replenish each trial. Fixing a
falling brick requires at least30 frames; the intended use is after settlement.
From trial3, a warned gentle breeze occurs after everyfourthdrop. Fixes resist it.
Hint predicts several simulated placements and positions the active brick; it
reduces the no-hint star. A suggestion can still be upset by later placement.
Stars: complete/no lost bricks/no hint. First reward12+3stars; replay5+3stars.
Permanent three-level wider foundation and more fixing charms cost18+18rank.
Six opening trials (6/8/10/12/14/14 bricks), then seeded continuing trials with
all seven polyomino shapes,4sky palettes and bounded14-brick physics towers.
Retry keeps coins/upgrades; it rerolls later shape sequences. Trialbook confirmed
replay, automatic local save/Continue, original sound with saved mute.
Physical bodies/poses/velocities/sleeping state are rebuilt after reload; contact
solver caches are recreated, so live unanchored bodies may settle slightly differently.
Keyboard:Left/Right move,Up/R rotate,Down/Space drop,F Fix,H hint,P/Escape pause.
English UI; touch/mouse, portrait/landscape, offline local assets, Canvas2D,
DPR capped1.5/45FPSdraw/60Hzphysics,noCDN/imagegen/commercial assets.
Open index.html directly or upload this folder to a static host. Blocked storage
can disable saving. Original code/art/tones; Steam Tricky Towers437920 reference:
physics bricks, unstable towers,limited magic and fairy-tale silhouettes. This is
an original compact solo browser interpretation,not its art/maps/online multiplayer.
