# Little Rail Garden

A small, original, English HTML5 route-building game. Inspired by the track-building premise of Unrailed!, but presented as a calm single-player puzzle: no resource gathering, time pressure, multiplayer or commercial game assets are included.

Tap a highlighted adjacent square to add track, collect optional stars, and connect to the station. The train follows the track. Undo removes the last piece and restart resets the current route. Completing a route unlocks the next; the best rating on each route is stored locally. All six authored routes have a possible path collecting all three stars. Tap Routes to revisit unlocked routes.

Touch or mouse; responsive portrait and landscape layout. Open index.html in a browser. There are no external dependencies. The forest background was generated for this game; train, tiles, interface, sounds and code were made for the game.
