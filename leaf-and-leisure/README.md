# Leaf & Leisure
Original mobile HTML5 incremental garden sweeping game. Inspired by the clear/upgrade/automate loop of Leaf Blower Revolution, with original pixel artwork, suction physics and sound.

Hold and drag the nozzle across leaves to collect them. Leaves swirl inward and become mulch immediately. Upgrade suction, widen the nozzle, and hire automatic gardeners (up to 14). Every 35 leaves charges a Golden Swirl, which temporarily triples suction and expands its area. Clear 85% to enter the next garden; spotless gardens award a larger bonus. Six garden palettes, eighteen collectible leaf species and endlessly repeated gardens with increasing value. Progress and current leaf positions save locally. Helpers run while visible; dialogs and hidden tabs pause. No offline earnings.

English UI, phone portrait/landscape and desktop layouts. No external libraries or network assets. Extract the ZIP and serve index.html on GitHub Pages or any static host. Packaged index is self-contained; editable sources are included. Sound starts after interaction and can be muted.
