PIP IS YOU — SMALL WORDS. BIG POSSIBILITIES.

A self-contained HTML5 rule-changing puzzle game inspired by Baba Is You's physical word rules, dark garden boards, compact pixel silhouettes and surprising object interactions. All sprites, font glyphs, maps, code and synthesized audio are original, made locally. This is an independent small adaptation, not the original commercial game or its full ruleset.

PLAY
Open index.html directly, or host the files together on a static HTTPS website. No build, dependencies, remote fonts or network assets are required.

Phone: swipe the board, or hold the directional buttons.
Keyboard: arrows / WASD. Z undo. R restart prompt.

Push words into horizontal or vertical SUBJECT IS PROPERTY sentences.
YOU controls an object. WIN makes it a finish. STOP blocks movement. PUSH makes an object movable. SINK removes itself and another object sharing its tile. HOT destroys a MELT object. OPEN and SHUT remove each other.
An object name after IS transforms the subject into that object. Text is always pushable unless visibly bolted down. Garden hedges always block. Bolted rules stay fixed. A rule changes immediately after a successful move.

CONTENT
18 authored puzzles across Mossy Meadow, Midnight Pond and Twilight Garden. Four completions in a chapter unlock the next chapter. All puzzles in an unlocked chapter can be selected; no forced linear bottleneck. Today's Thought selects a daily puzzle from the entire set. Optional hints and restart-with-trail assistance. Unlimited undo (last 100 moves); no timer, energy, payments or random gambling.

Best step counts, collected thoughts, gold medals, duck charms and the exact current board (including undo history and active hint trail) save in this browser. Gold medals require an unassisted finish at or below the displayed authored reference path length. This target is a reference solution, not a claim of mathematical optimality. Charms unlock at 4, 10 and 18 collected thoughts. Audio starts only with a user action; it is optional. Browser storage may be cleared by the browser or platform.

Mobile portrait and landscape layouts, pointer capture and touch-repeat controls, keyboard support, reduced-motion preference, hidden-tab rendering suspension and no network dependencies. A modern browser with Canvas2D and Web Audio is recommended.

LIMITS
This version supports one subject / IS / one property or noun per sentence, plus multiple separate sentences. It does not implement AND, NOT, HAS, arbitrary text conversion or the full Baba Is You grammar. No multiplayer or cloud accounts. Static garden hedges and fixed rule words cannot be moved.
