# Corner Crew — Pixel Edition

Hold the sign to stop traffic and guide up to three pedestrians across. Keep holding until they reach the other side, then release to let cars pass. Six shifts introduce faster traffic, a second opposing lane, slower walkers and urgent vehicles. Completed shifts and best stars are stored locally in the browser; reloading restarts the current shift. Spacebar can also hold the sign.

The game runs from a static server with Canvas 2D and no external network requests or image-generation assets. Artwork is drawn as original pixel shapes in art.js. The game rules and browser storage key remain compatible with the earlier edition.
