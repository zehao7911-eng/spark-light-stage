# Corner Crew

A small independent English-language touch game inspired by the visible objective, interaction and progression qualities in the user's game recordings. The traffic crossing mechanic, code, interface and generated artwork are original for this project; it is not a copy of any of the recorded games.

Hold the sign to stop traffic and guide up to three pedestrians across. Keep holding until they reach the other side; release so cars can pass before the queue becomes impatient. Six shifts introduce faster traffic, a second opposing lane, slower walkers and more urgent cars. Complete a shift to unlock the next. Best stars and unlocks are stored locally in your browser; an interrupted shift restarts when the page is reloaded. Spacebar can also hold the sign. Audio begins after user interaction and can be muted.

Run a static server from this directory and open index.html. The game requires Canvas 2D and a browser with WebP support. It includes three generated backgrounds and separate generated character and car sprites; their movement is programmatic, not frame-by-frame sprite animation.
