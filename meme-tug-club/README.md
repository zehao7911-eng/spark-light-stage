# Meme Tug Club

A small English-language, touch-first tug-of-war game inspired by internet meme culture. Drag left on the play field or pull button, or tap the button. Pull the flag to the left to win. The energy bar recovers between pulls; the hype bar builds a stronger pull. A well-timed long drag during an opponent's warning gives a bonus. A win earns coins to improve pull strength. Six initial rivals lead to a repeatable rotation with stronger pulls. Progress, coins, upgrades and sound choice are stored in browser local storage; an interrupted match restarts at that round.

The 2D artwork was made for this project with image generation, including two matching effort expressions, and is combined with independently written code, typography, UI, particles, and synthesised sounds. These are meme-inspired reinterpretations. No reference game code or assets are included.

Reference observed: Rezona's Blep Cat (https://rezona.ai/game/pgcserver/play/mVFCTOfk): wake and petting interaction with a visible smile and reward. This tug-of-war game uses a different interaction. References to internet meme culture include Doge, a sneaker-wearing shark, a cappuccino dancer, a banana cat and an absurd wooden character.

Open `index.html` from a static web server. All game files are local; there is no network dependency. The game can also be served from a static web host. Input: touch drag, tap, mouse, Space or left arrow. Escape pauses. Sound begins after interaction when the browser permits it.

Pause and press RESET PROGRESS twice to start over.
