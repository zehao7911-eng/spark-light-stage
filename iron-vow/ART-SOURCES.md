# Artwork sources

Source game: **Rebirth Blade — 1v1 Boss Duel**, publicly available on Rezona.

Reference page: https://rezona.ai/game/pgcserver/pv/fNvbHcfO/v1/dist/index.html

Media base URL: https://rezona.ai/game/pgcserver/pv/fNvbHcfO/v1/dist/assets/

Included reference artwork: castle and crypt backgrounds; four poses of each of two armoured opponents; foreground player and shield. Full original filenames, URLs, hashes and dimensions are in `assets/PROVENANCE.json`. Runtime filename mapping is in `assets/runtime-art.json`.

No reference music, sound effects or game source code is distributed. Runtime effects, interface icons, combat logic, progression, synthesized sound and interface code are written for Iron Vow. The reference artwork is credited to its original creators; no authorship or exclusive-rights claim is made for that artwork. A public remix flag is recorded as platform metadata, not represented as an independent open-source license grant for the media.
