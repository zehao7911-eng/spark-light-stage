# Cat Chaos

Original, dependency-free HTML5 street-mischief game. All artwork is drawn locally using Canvas; no external assets or network requests are required.

Drag or hold on the street to steer the cat. Pounce scatters props and can start nearby chain reactions. Pull tablecloths, scatter pigeons, kick balls, knock over displays and collect fish. Avoid the shopkeeper's broom to protect your combo. Complete three jobs each day; new days change the street, palette, layout and objectives. Fish unlock permanent cat accessories. Progress saves locally.

Desktop: pointer steering, WASD/arrow keys, Space to pounce. Touch: drag/hold to steer and tap Pounce. Sound starts after a user gesture. Pause and background-tab suspension are supported. No real-money transactions.

Serve this folder using any static HTTP server or upload it to GitHub Pages. `index.html` is at the ZIP root.
