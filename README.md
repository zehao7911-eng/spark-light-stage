# SPARK — The Light Stage

An immersive HTML5 dance stage with animated character and facial expressions, a reflective floor, moving lights, floating particles, and three lighting palettes.

## Controls

- Select **Sound · Off** to enable the soundtrack.
- Play/pause, seeking, and playback speed also control the music.
- Drag to orbit and scroll to zoom.
- Select a lighting color or enable the automatic orbit camera.

## Download and run locally

Download **SPARK-Stage.zip** from this repository's Releases page. Extract it, run `node serve.cjs` with Node.js, and open http://127.0.0.1:4173.

The release archive includes the local server and all assets. The files on the main branch are the static GitHub Pages version and can be served by any static HTTP server.

The supplied music lasts about 12.1 seconds, and the animation lasts 12.3 seconds. With sound enabled, the dance follows the soundtrack clock and loops with it. Browsers require a click before starting audio.
