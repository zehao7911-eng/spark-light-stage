# Lantern Bay

An original illustrated HTML5 fishing exploration game inspired by DREDGE's sail–fish–sell–upgrade loop. No external dependencies, downloads or build step. All artwork, synthesized sound and code are original.

## Play

Drag the steering pad, use WASD/arrows, or tap open water to plot a route. Cast within the circular shoals. Tap Reel as the needle crosses the gold band three times. Three misses release the fish without consuming the shoal. The hold starts at five fish. Sail to Lantern Harbor, Dock to sell, and buy engine, hold and rod upgrades. The Home button plots an obstacle-avoiding route home. The sea chart also accepts destination taps.

There are six islands, twelve fish species, four salvage caches, three levels of boat upgrades and four boat paints. Higher-tier shoals need better rods; Moon Mothfish appears at night. Shoals replenish, the day/night cycle continues, and harbor orders reward repeated voyages. The journal and voyage save locally. Leaving during a fishing attempt does not consume a fish.

Run on a static server or GitHub Pages. Mobile rendering is limited to approximately 30 FPS, DPR to two. Static terrain is cached; audio requires a gesture and pauses when hidden. No real money or paid purchases.
