# Prism Atelier

An original, dependency-free HTML5 stained-glass restoration game. Drag each pane into its home, rotate later panes with the Rotate button, wipe away dust, and collect the restored window. Six original illustrated themes cycle through unlimited shuffled puzzles. Progress and collection are saved locally.

Serve this folder with any static web server, or upload it to GitHub Pages. No build step or external assets are required. Touch, mouse, and the R rotation shortcut are supported. There is no timer or penalty; hints are unlimited.

Design inspiration: the satisfying arrangement interactions of A Little to the Left. All artwork and code in this package are original.
