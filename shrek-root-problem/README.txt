SHREK: ROOT PROBLEM
Unofficial fan mini-game. Shrek and Donkey belong to DreamWorks Animation.
Original procedural geometry, animations and synthesized sound. No extracted commercial assets.

Drag down anywhere on the scene. Release when the marker is inside the green zone.
Three successful pulls clear a patch. Three misses let the onion win.
Pulling too hard for too long automatically snaps the stem. Let go sooner!
Each patch rotates six underground surprises. Green zones narrow gently over time.
Desktop: hold Space to increase force; release in green. Escape pauses.
Pause or leaving the page cancels a held pull without costing a life.
Progress and mute preference are saved locally when browser storage is available.
Save the Nonsense downloads a PNG of the 3D scene.

Open index.html directly or host the folder on any static HTML5 host.
No network dependencies, installation, account, or payment.
