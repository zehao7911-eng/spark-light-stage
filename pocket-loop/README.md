# Little Loop Express

An original small HTML5 driving game inspired by the passenger collection and lengthening bus in Snakeybus. This is a separate 2D game with original art and no assets from Snakeybus.

Tap a destination or drag to steer. Pick up three passengers, then drive to the glowing star to drop them off. Each delivery adds a carriage; traffic begins after two deliveries. Avoid traffic to keep your three hearts. Complete eight deliveries to finish; your best delivery count is saved in the browser.

Keyboard: arrow keys or WASD. Pause with the pause button. Sound can be switched off. Open index.html in a modern browser. All files are local. The town backdrop was generated for this game; gameplay objects, user interface, code and sounds were created for it.
