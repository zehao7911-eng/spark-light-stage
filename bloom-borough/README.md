# Bloom Borough

An original, dependency-free HTML5 island-building puzzle inspired by ISLANDERS' building-adjacency scoring. All illustrated artwork, code and synthesized sound are original.

Choose a card, tap an empty plot and press Place. Dragging a card onto a plot also places it. Connections preview positive and negative neighbor bonuses. Read the short affinity line above the cards. Z undoes the latest placement; 1–3 selects cards and Space places the selected building.

Reach parcel thresholds to choose one of three eight-piece building packs. Reach the town goal to save a postcard and sail to the next island, or continue decorating. One six-piece care parcel is available if a town runs out of cards. Islands rotate through blossom, harvest and frost palettes. Eight building types, paths, moving townspeople and windmills bring the miniature to life. The most recent twelve postcards and current island persist locally. Goals increase across an unlimited island journey. Scores use a six-neighbor radius except markets and lighthouses, which use two rings.

Serve this directory through any static server or GitHub Pages. Touch, mouse and keyboard are supported. Mobile drawing targets approximately 30 FPS with DPR capped at two. Audio unlocks on interaction; animations pause when the document is hidden. No external assets or build step are needed.
