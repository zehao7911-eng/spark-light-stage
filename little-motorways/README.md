# Little Motorways

A compact HTML5 road-network strategy game inspired by Mini Motorways. All artwork is original Canvas drawing; all audio is synthesized. No remote dependencies or commercial game assets.

Draw roads between houses and destinations of the same color. Cars find paths, queue in traffic, make deliveries and return home. Building demand increases as the city grows. Choose roads plus a bridge, or roads plus an expressway each week. Bridges are placed automatically on water cells. Expressways are drawn between two endpoints and bypass traffic.

Erase closes roads to new journeys; existing cars finish using them before roads disappear and resources return. Undo restores the last road stroke. Pause, half/double speed, night palette, endless continuation, score records, and three unlockable maps are included. Early arrivals teach the rules; later arrivals vary between runs.

Touch or mouse: drag to draw. Pinch to zoom and use two fingers to pan; the zoom button offers preset scales. E/R switch erase/road, Z undo, Space pause. The logical map rotates for portrait screens without changing the network. Opening the menu or a weekly upgrade pauses simulation. Drawing slows time. Hidden tabs pause automatically.

Open index.html directly, or serve the folder. The packaged index includes every dependency. Best scores, map selection and settings save locally; current cities are not saved between reloads. Tested in mobile browser emulation; no physical handset benchmark is claimed.
