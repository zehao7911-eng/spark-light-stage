# Oddshot

An original HTML5 photography discovery game inspired by TOEM's photography, exploration and little character mysteries. Four orbitable illustrated dioramas contain twelve authored requests. All code, illustrations and synthesized sounds are original. No image generation, external assets or dependencies.

Drag the scene to frame a photograph. Turn the view with the arrow buttons, switch 1×/1.6×/2.4× lenses, use Call to invite shy characters, and Flash to reveal ghosts. Select a request card, fit its subjects inside the viewfinder, and Snap. Some requests need multiple subjects, an unobstructed angle, or alignment of the moon inside an arch. Hint centers the requested area but does not perform its interaction. Keep photographs, earn composition stars and stamps, and travel onward after all three local requests are complete. Earlier places remain available for free photography.

Arrow keys rotate, C calls, F toggles flash and Space takes a photograph. Photos and stamps save locally; the last twenty-four photographs are retained, with a smaller fallback album if browser storage is full. Paused photo panels stop invitation timers. Mobile draws at approximately 30 FPS with DPR capped at two. Serve the folder with any static server or GitHub Pages.
