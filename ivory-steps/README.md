# IVORY STEPS

Eight original architectural puzzles for desktop and mobile browsers. Pastel isometric monuments, a little ivory traveler, rotating bridges, lifts, linked mechanisms, collectible petals and perspective connections.

## Play

Open index.html, then BEGIN THE JOURNEY. Tap a reachable walkway to walk. Use the round arrow below a bridge to turn it, including while standing on it. The square arrow moves the lift. The diamond rotates the viewpoint. A question mark gives a hint; the curved arrow undoes a move. Gather all petals before reaching the domed door.

There is no timer or failure. Completed monuments unlock the next one. The menu lets you replay unlocked puzzles. Progress and best move counts are stored locally when the browser permits it. R/T turn bridges, L moves the lift, V changes the view and Z undoes.

## Offline and hosting

The ZIP has index.html at its root. That file embeds the stylesheet and JavaScript and needs no downloads or internet connection. The separate style.css, levels.js and game.js are editable source copies. Upload the root files to a static HTML5 host, including GitHub Pages. Mobile uses touch input, responsive portrait/landscape layout and a maximum pixel ratio of 2. Sound starts only after interaction.

## Scope and credits

Inspired by the spatial-puzzle presentation of Monument Valley Panoramic Edition. This is an original, compact browser interpretation with eight authored layouts and procedural canvas artwork. It does not include the commercial game's maps, assets, full campaign or arbitrary Escher geometry. The authored perspective seam becomes connected only in its correct camera orientation. All images and sounds here are drawn or synthesized by the code. No third-party runtime or CDN is required.
