Complete source-game foundation

This is a modernized adaptation of Christopher Scott Hernandez’s complete Whack-A-Mole game (2010, MIT). Its live / kill / move / togglePop / reset / step lifecycle, timed-hit scoring and finite target loop form the new deterministic game model. The DOM timer renderer has been replaced by a responsive Canvas presentation. Multi-target slots, nine shifts, armor, friendly workers, Mega Bonk, profile/save and all new artwork are additions.

Unmodified original game code · Original MIT license · Source SHA-256 manifest

No original game images, fonts, audio, advertisements, analytics or third-party branded characters are reused. This is an original project and is not affiliated with Supercell.

Original art system

The cover, character/prop atlas, three environment panels and icon were generated using the built-in image_gen tool. The cover establishes character identity, materials, lighting and palette; subsequent assets use it as a reference. The icon received a separate safe-area revision. Atlas rectangles are measured from individual transparent silhouettes, not blindly sliced into grid cells.

Exact generation prompts · Sprite atlas coordinates and source filenames · Transparent character/prop sheet · Three environment panels

Audio & mobile

Original synthesized impact, metal and reward tones use Web Audio after a user gesture. No prerecorded music. Portrait and landscape layouts, 44px controls, keyboard 1–9, DPR capped at 1.5, bounded effects, background pause and local save. Mobile viewport testing does not certify every physical phone.

All gameplay-facing text is English. No account, payment or external runtime service is required.
