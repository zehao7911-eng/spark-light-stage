# Mouseberry Sky

An original 3D mouse-and-fruit sky platform adventure. Pull downward to set leap distance and sideways to aim, then release. The dotted ballistic arc and green/red destination ring preview the landing. Aim near the center for150points/perfect streaks. HOP or Space is a gentle assisted leap to the next island (100points, does not count as a precision-perfect). Twelve collectible fruit stars per trail, checkpoint flags every four islands, moving fruit from the middle of the route. Falling returns to the last flag; already collected stars/points remain, and revisiting cannot farm points. No failure timer. Complete the route for1–3stars: finish, collect10stars, make8perfect leaps. Further trails change the fruit order, layout, moving pads and landing width; progression repeats base fruit types rather than claiming unlimited distinct worlds.

All UI English. Pointer/touch drag, HOP button, Space assisted hop, Escape pause. Local saves retain active airborne/grounded state, unlocked trail and best stars. Storage failure is nonfatal. Sound starts on interaction. Pause/hidden stops simulation, rendering and new audio. Low quality caps render scale1.0 and disables shadows; high caps1.5/1024px shadow. Fixed-step physics separates simulation from display. No external CDN/API/account/analytics. Serve this extracted folder through HTTP/HTTPS, e.g. `python -m http.server 8000`; open index.html. Direct file:// may block modules.

Fruit faces are original procedural canvas textures; islands, flags, gates, clouds and collectibles are original meshes.
