# Roll & Grow

An independent browser game inspired by the growing-object collection shown in the user's video 8.mp4. Original code and procedural 3D artwork; no video assets or original game code are included.

Drag on the play area to roll. Gather small objects to grow and unlock larger ones. Reach the target size before time runs out. A boost is available every few seconds. Finish each of the three rooms to unlock the next; best stars and unlocked rooms are stored locally on the device. Keyboard: WASD or arrow keys, Space for boost.

Run through any static web server. Works on touch or desktop with WebGL. Audio starts after interaction. Pause when switching tabs. Three.js is bundled; its license is in vendor/three-LICENSE.txt.
