# GameWave import

Upload CHUTE-SCOOT.zip with index.html at the archive root. The game starts independently in GitHub Pages, a normal browser or an embedded preview.

The optional adapter discovers window.neonlib at runtime. The first accepted takeoff starts a route session. The final successful delivery ends it. A retry or the next parcel uses the same live session. If a saved partial route is reloaded, the next accepted takeoff starts the resumed session. Changing or restarting an active route ends that attempt. Menus and reward callbacks do not start a route.

chute-scoot-v1 stores this game's local profile and route checkpoint. The cloud payload contains only this game's profile. Best records merge by maximum and earned rewards by union. An active route stays local. The optional viewport uses CSS width and height, independent of density.

A confirmed positive like unlocks a gold cap badge. A successful direct comment unlocks a multicolor landing celebration. Both are optional, claimed once per saved profile and shown in the settings panel when supported. Registration failure leaves play available. Already-earned cosmetics remain usable.

[Official GameWave SDK reference](https://rg975ojk5z.feishu.cn/wiki/MQg7wMknzieOkukxyWVc4UB0nDh) checked November 6, 2026. SDK tests use controlled mocks. Real GameWave App import and social callbacks require an App-side test.
