# Gemlight Atelier
Original mobile HTML5 pixel mining and gem cutting game. No dependencies, network assets or accounts required.

Hold arrow buttons or WASD/arrows to move and drill. Tap nearby terrain to travel and mine toward it. Connected gems of the same type break together. Scan reveals hidden veins. Return to keep all collected gems. Choose a commission, then tap CUT three times as the moving light crosses gold. Perfect cuts increase the price. Upgrade the drill, backpack, scanner and cutting wheel with your earnings. Six gem types, six designs and progressively deeper generated mine sectors.

Progress, active mining trips and unfinished crafting save locally. Extract and serve index.html on any static host, including GitHub Pages. The packaged index is self-contained; source files are included for editing. Sound starts after interaction and can be muted.
